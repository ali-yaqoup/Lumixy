My Work in Lumixy App

1. Home Page
Welcome section and search entry point
Display of available service categories
Dynamic listing of service providers
Navigation to service details
2. Search Page
Search bar with category filters
Dynamic results based on user input
Provider cards with details and navigation
3. About Page
App information and branding
Call-to-action for service providers to join
Contact and support information
All these pages were implemented by me (UI/UX, logic, and backend API integration).
